# Задача 2. Треугольник Паскаля DSBA

## Условие

Даны два числа `n` и `m`. Создайте двумерный массив `n × m` и заполните
его по следующим правилам:

- Числа в первой строке и первом столбце равны 1.
- Для всех остальных элементов:
  `a[i][j] = a[i-1][j] + a[i][j-1]`
  (сумма верхнего и левого соседа).

## Идея решения

Идём по строкам слева-направо, сверху-вниз. Первая строка и первый
столбец — единицы. Каждый следующий элемент — сумма верхнего и левого
соседа, которые к этому моменту уже посчитаны.

## Ввод

Два числа: `n` и `m`. Оба меньше 100.

## Вывод

Заполненный массив `n × m`. Числа разделены пробелами.

## Пример

Ввод:
```
3 3
```

Вывод:
```
1 1 1
1 2 3
1 3 6
```

## Как запустить

```bash
g++ -std=c++23 -O2 solution.cpp -o solution
./solution
```

Программа ждёт ввод с клавиатуры. Введи `3 3` и нажми Enter.

## Ограничения

- Время: 1 сек
