# Задача 8. Печать C++23

## Условие

Напишите функцию `void print(int* arr, int n)` для печати одномерного
массива.

## Идея решения

Проходим по массиву и выводим элементы через пробел. Чтобы не ставить
лишний пробел после последнего элемента, проверяем индекс: пробел
печатается только если `i < n - 1`.

## Ввод

Число `n` — количество чисел массива, затем `n` строк с самими элементами.

## Вывод

Элементы массива, разделённые пробелами.

## Пример

Ввод:
```
5
4
3
2
1
6
```

Вывод:
```
4 3 2 1 6
```

## Как запустить

```bash
g++ -std=c++23 -O2 solution.cpp -o solution
./solution
```

Программа ждёт ввод с клавиатуры. Введи числа по одному, каждое с новой строки.

## Ограничения

- Время: 1 сек
- Память: 64 МБ
