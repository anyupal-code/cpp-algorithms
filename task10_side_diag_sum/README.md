# Задача 10. Побочная диагональ C++23

## Условие

Напишите программу, содержащую две функции:

1. `int** read_matrix(int n)` — для чтения квадратной матрицы размера
   `n × n` (элементы каждой из строк матрицы разделены пробелами,
   строки разделены переносом строки).
2. `int find_sum(int** matrix, int n)` — для подсчёта суммы на побочной
   диагонали матрицы.

## Идея решения

`read_matrix` выделяет память через `new` (массив указателей, затем
для каждой строки — массив `int`), читает элементы и возвращает
`int**`. `find_sum` идёт по строкам `i` от `0` до `n-1` и складывает
элементы `matrix[i][n-1-i]` — это и есть побочная диагональ.

## Ввод

Число `n` — размер матрицы, затем `n` строк, содержащих `n` целых
чисел, разделённых пробелами.

## Вывод

Сумма на побочной диагонали матрицы.

## Пример

Ввод:
```
2
1 2
3 4
```

Вывод:
```
5
```

Пояснение: побочная диагональ — `2` и `3`. Сумма = `2 + 3 = 5`.

## Как запустить

```bash
g++ -std=c++23 -O2 solution.cpp -o solution
./solution
```

Программа ждёт ввод с клавиатуры. Введи `n`, затем `n` строк с числами.

## Ограничения

- Время: 1 сек
- Память: 64 МБ
