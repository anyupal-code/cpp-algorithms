# Задача 7. Нули в конец C++23

## Условие

Дан массив, состоящий из целых чисел. Напишите программу, которая
сдвигала бы все нули, содержащиеся в массиве, в конец последовательности,
при этом сохраняя порядок ненулевых элементов.

**Не разрешается** использовать дополнительный массив. Постарайтесь
также минимизировать общее число операций.

## Идея решения

Метод двух указателей. Указатель `i` — позиция, куда класть следующий
ненулевой элемент; указатель `j` перебирает массив. Если `arr[j] != 0`,
копируем его в `arr[i]` и увеличиваем `i`. Оставшиеся позиции от `i`
до `n-1` заполняем нулями. Сложность `O(n)`, память `O(1)`.

## Ввод

Число `n` — размер массива, затем `n` чисел.

## Вывод

Массив, в котором все нули сдвинуты в конец, числа через пробел.

## Пример

Ввод:
```
5
0
1
0
3
12
```

Вывод:
```
1 3 12 0 0
```

## Как запустить

```bash
g++ -std=c++23 -O2 solution.cpp -o solution
./solution
```

Программа ждёт ввод с клавиатуры. Введи числа по одному, каждое с новой строки.

## Ограничения

- Время: 1 сек
- Память: 64 МБ
