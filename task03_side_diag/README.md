# Задача 3. Побочная диагональ с использованием массивов DSBA

## Условие

Дано число `n`. Выведите таблицу `n × n` по правилу:

- Числа **на побочной диагонали** (идущей из правого верхнего угла
  в левый нижний) равны **1**.
- Числа **выше** этой диагонали равны **0**.
- Числа **ниже** этой диагонали равны **2**.

## Идея решения

Побочная диагональ задаётся условием `i + j == n - 1`. В зависимости
от знака `(i + j) - (n - 1)` ставим 0 (выше), 1 (на диагонали) или 2 (ниже).

## Ввод

Одно число `n` (`n < 100`).

## Вывод

Таблица `n × n`. Числа разделены пробелами.

## Пример

Ввод:
```
2
```

Вывод:
```
0 1
1 2
```

## Как запустить

```bash
g++ -std=c++23 -O2 solution.cpp -o solution
./solution
```

Программа ждёт ввод с клавиатуры. Введи `2` и нажми Enter.
