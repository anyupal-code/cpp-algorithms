# Задача 4. Квадратичная сортировка C++23

## Условие

Требуется отсортировать массив любой квадратичной сортировкой.

Необходимо написать функцию, прототип которой выглядит как
`Sort(int* begin, int* end)`,
где `begin` — указатель на начало сортируемого отрезка,
`end` — указатель на конец сортируемого отрезка.

## Идея решения

Используем сортировку вставками: идём по массиву от второго элемента
до конца, запоминаем текущий элемент как `key` и сдвигаем все элементы
слева, которые больше `key`, вправо, пока не найдём место для вставки.
Сложность — `O(n²)`, память — `O(1)`.

## Ввод

Число `n` — количество чисел в массиве, затем `n` строк с элементами.

## Вывод

Отсортированный по неубыванию массив, числа через пробел.

## Пример

Ввод:
```
2
3
1
```

Вывод:
```
1 3
```

## Как запустить

```bash
g++ -std=c++23 -O2 solution.cpp -o solution
./solution
```

Программа ждёт ввод с клавиатуры. Введи `2`, Enter, `3`, Enter, `1`, Enter.

## Ограничения

- Время: 1 сек
- Память: 256 МБ
