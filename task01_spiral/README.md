# Задача 1. Спираль C++23

## Условие

Требуется заполнить массив размера `n × n` единичками по спирали,
начиная с верхнего левого угла и двигаясь по часовой стрелке.

## Идея решения

Идём по спирали от левого верхнего угла по часовой стрелке: ставим 1
в текущую клетку и пробуем шагнуть вперёд. Если впереди граница или
занятая клетка, **или** клетка через одну занята (правило «зазора») —
поворачиваем направо. Останавливаемся в тупике, когда все четыре
направления заблокированы.

## Ввод

Одно число `n` — нечётное, натуральное, не превосходит 50.

## Вывод

Построенная спираль `n × n` из нулей и единиц, построчно.

## Пример

Ввод:
```
7
```

Вывод:
```
1111111
0000001
1111101
1000101
1011101
1000001
1111111
```

## Как запустить

```bash
g++ -std=c++23 -O2 solution.cpp -o solution
./solution
```

Программа ждёт ввод с клавиатуры. Введи `7` и нажми Enter.

## Ограничения

- Время: 1 сек
- Память: 256 МБ
