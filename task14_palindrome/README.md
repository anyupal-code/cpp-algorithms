# Задача 14. Палиндром

## Условие

Дана строка, состоящая из строчных букв латинского алфавита и пробелов.
Проверьте, является ли она палиндромом **без учёта пробелов**
(например, «no lemon no melon»).

**Требование:** реализуйте решение в виде функции, которая принимает
строку и возвращает `true`/`false` в зависимости от того, является
ли строка палиндромом или нет. Используйте эту функцию в функции
`main()` для решения задачи.

Входные данные — одна строка длиной не более 100 символов, включая
пробелы. Между словами может находиться произвольное количество пробелов.

## Идея решения

Метод двух указателей. `left` идёт с начала строки, `right` — с конца.
Внутренние `while` пропускают пробелы с обеих сторон. Сравниваем
символы: если хотя бы одна пара не совпала — возвращаем `false`.
Если указатели встретились — `true`.

## Ввод

Одна строка (может содержать пробелы). Читается целиком через `getline`.

## Вывод

`yes`, если строка — палиндром, иначе `no`.

## Пример 1

Ввод:
```
f
```

Вывод:
```
yes
```

## Пример 2

Ввод:
```
kk
```

Вывод:
```
yes
```

## Пример 3

Ввод:
```
ok
```

Вывод:
```
no
```

## Как запустить

```bash
g++ -std=c++23 -O2 solution.cpp -o solution
./solution
```

Программа ждёт ввод строки целиком (с пробелами). Введи и нажми Enter.

## Ограничения

- Время: 1 сек
- Память: 64 МБ
