# Задача 12. Название дня недели C++23

## Условие

По номеру дня недели (нумерация с единицы) выведите его сокращённое
название. Названия должны быть такими:

```
mon
tue
wed
thu
fri
sat
sun
```

## Идея решения

Заводим массив из 8 строк: индекс `0` — пустой, индексы `1..7` —
сокращённые названия дней недели. По числу `n` просто выводим
`days[n]`.

## Ввод

Число от 1 до 7.

## Вывод

Название дня недели из трёх маленьких латинских букв.

## Пример 1

Ввод:
```
1
```

Вывод:
```
mon
```

## Пример 2

Ввод:
```
2
```

Вывод:
```
tue
```

## Пример 3

Ввод:
```
3
```

Вывод:
```
wed
```

## Как запустить

```bash
g++ -std=c++23 -O2 solution.cpp -o solution
./solution
```

Программа ждёт ввод с клавиатуры. Введи число от 1 до 7.

## Ограничения

- Время: 1 сек
- Память: 64 МБ
