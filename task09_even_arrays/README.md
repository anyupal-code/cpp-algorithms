# Задача 9. Чётные массивы C++23

## Условие

Напишите программу, создающую для каждого введённого числа массив,
состоящий из чётных чисел не больше заданного, и выводящую элементы
этого массива через пробел.

## Идея решения

Читаем числа по одному до `-1`. Для каждого числа `x` выводим все
чётные от `0` до `x` включительно через пробел, затем переходим
к следующему числу.

## Ввод

Последовательность целых неотрицательных чисел, которая завершается `-1`.
Количество чисел заранее неизвестно. Числа вводятся каждое с новой строки.

## Вывод

Для каждого введённого числа — строка из чётных чисел не больше заданного,
записанных через пробел.

## Пример

Ввод:
```
1
2
5
6
-1
```

Вывод:
```
0
0 2
0 2 4
0 2 4 6
```

## Как запустить

```bash
g++ -std=c++23 -O2 solution.cpp -o solution
./solution
```

Программа ждёт ввод с клавиатуры. Введи числа по одному, каждое с новой
строки. Последнее — `-1`, оно сигнализирует об окончании ввода.

## Ограничения

- Время: 1 сек
- Память: 64 МБ
